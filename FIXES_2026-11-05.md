# Targeted fixes: 2026-11-05

## Authentication
- **Log Out now really signs out** and removes the local token/last username even when biometrics are enabled. Previous builds kept the old session alive after logout. A device that was locked under that legacy mechanism is reset to a signed-out state during startup. Sign-out also clears the local token if the server is temporarily unreachable; the backend stale-attendance sweep may subsequently close the attendance record.
- Biometric unlock is restricted to the *same already-authenticated username*. Changing username requires that account’s password. Device authentication now requires biometrics rather than allowing a PIN fallback.
- **Android's biometric API does not identify which enrolled fingerprint belongs to which human/account.** Separate fingerprint identities on the same phone cannot be guaranteed. Use password-based login when switching accounts. An account-scoped biometric unlock can only unlock a still-authenticated session, not log into a different account.

## Dashboard and performance
- Mobile dashboard section titles wrap within available width, avoiding the observed yellow/black RenderFlex overflow.
- Trend badges truncate rather than overflowing narrow cards.
- Coalesces overlapping dashboard API refreshes instead of issuing redundant concurrent requests.
- Caches the secure token *in memory for the duration of one app run*, avoiding a secure-storage read on every HTTP call; stored token remains in the Android Keystore.
- Background stale-attendance scan now runs once per minute instead of six times per minute; 30 minute stale threshold unchanged.

## Attendance hours
- Extremely long attendance spans (e.g. an open/closed record spanning multiple days) no longer display as 200+ working hours. AttendanceDurationService caps each uninterrupted cycle at 16 hours for displayed totals, without altering historical records. Roster labels for closed sessions longer than 16 hours show `Review checkout` instead of a misleading number. Such records still require manual auditing: these are display safeguards, not automatic corrections to attendance data.
